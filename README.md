# Автоматизована Система Керування Воротами

Проект для автоматизації процесу відкриття та закриття воріт з використанням Raspberry Pi 5, камер та моделей машинного навчання для детекції автомобілів і розпізнавання номерних знаків.

## Опис Проекту

Метою проекту є створення інтелектуальної системи, яка автоматично керує воротами на основі візуальної інформації та списку авторизованих транспортних засобів. Система використовує дві камери (для в'їзду та виїзду), моделі машинного навчання для виявлення автомобілів, детекції номерних знаків та розпізнавання символів. Взаємодія з Google Sheets використовується для перевірки авторизації та логування подій. Керування воротами здійснюється через реле, а датчики (геркон та ультразвуковий) забезпечують безпеку та інформацію про стан воріт.

## Ключові Функції

* **Двокамерна система**: Окрема камера для зони в'їзду та виїзду.
* **Детекція автомобілів**: Використання моделі MobileNet SSD (`ssd_mobilenetv1.onnx`) для виявлення автомобілів у визначених зонах інтересу (ROI).
* **Розпізнавання номерних знаків**:
    * Детекція області номерного знаку за допомогою моделі `license.onnx` (на базі YOLO).
    * Розпізнавання символів на номерному знаку за допомогою моделі `ocr.pt` (на базі YOLO, обробляється бібліотекою Ultralytics).
* **Авторизація через Google Sheets**:
    * Перевірка розпізнаного номера у списку авторизованих.
    * Оновлення часу в'їзду для авторизованих авто.
    * Логування неавторизованих спроб.
    * Логування часу виїзду.
* **Автоматичне керування воротами**:
    * Відкриття воріт для авторизованих авто на в'їзд.
    * Негайне відкриття воріт при детекції авто на виїзд.
    * Автоматичне закриття воріт після проїзду автомобіля з урахуванням тайм-ауту та перевірки безпеки.
* **Безпека**:
    * Використання геркона для визначення стану воріт (відчинені/зачинені).
    * Використання ультразвукового датчика для виявлення перешкод у прорізі воріт та підтвердження проїзду.
    * Логіка переривання закриття воріт при виявленні нового автомобіля.
* **Логування**: Детальне логування роботи системи у файл та консоль.

## Апаратні Вимоги

* Raspberry Pi 5 (рекомендовано 64-bit OS, наприклад, Debian Bookworm)
* Raspberry Pi Camera Module 3 (для в'їзду)
* Raspberry Pi Camera Module 2 (для виїзду)
* Герконовий датчик (наприклад, MC-38) для визначення стану воріт.
* Ультразвуковий датчик відстані (наприклад, AJ-SPO4M або HC-SR04) для виявлення перешкод.
* Двоканальне реле для керування сигналами "OPEN" та "CLOSE" воріт (емуляція кнопок пульта).
* Відповідні з'єднувальні дроти, резистори (для дільника напруги для Echo УЗД, якщо потрібно), блок живлення.

## Програмне Забезпечення та Залежності

* Python 3.8+
* Основні бібліотеки перелічені у файлі `requirements.txt`. Серед них:
    * `opencv-python`
    * `numpy`
    * `onnxruntime`
    * `ultralytics`
    * `gspread`
    * `oauth2client`
    * `RPi.GPIO` / `gpiozero`
    * `picamera2`

## Налаштування та Встановлення

1.  **Клонування репозиторію** (якщо проект у Git):
    ```bash
    # git clone <your-repository-url>
    # cd automated_gate_system
    ```
2.  **Створення та активація віртуального середовища** (рекомендовано):
    ```bash
    python3 -m venv venv
    source venv/bin/activate
    ```
3.  **Встановлення залежностей**:
    ```bash
    pip install -r requirements.txt
    ```
4.  **Налаштування Google Sheets API**:
    * Створіть проект у Google Cloud Console, увімкніть Google Drive API та Google Sheets API.
    * Створіть обліковий запис служби (service account) та отримайте для нього ключ у форматі JSON.
    * Перейменуйте файл ключа на `credentials.json` та розмістіть його у директорії `config/`.
    * Надайте створеному обліковому запису служби права на редагування вашої Google Таблиці (поділіться таблицею з email адресою сервісного акаунта).
    * Переконайтеся, що URL вашої таблиці правильно вказаний у файлі `core/sheet_handler.py` (константа `YOUR_SPREADSHEET_URL`).
5.  **Розміщення моделей**:
    * Розмістіть файли моделей (`ssd_mobilenetv1.onnx`, `license.onnx`, `ocr.pt`) у директорію `models/`. Шляхи до них вказані у `main.py`.
6.  **Налаштування ROI (Регіонів Інтересу)**:
    * Запустіть скрипт `tools/roi_create.py`:
        ```bash
        python tools/roi_create.py
        ```
    * Дотримуйтесь інструкцій на екрані для визначення та збереження ROI для камер в'їзду та виїзду. Конфігурація буде збережена у `config/roi_config.json`.
7.  **Конфігурація пінів та інших параметрів**:
    * Основні шляхи, номери GPIO пінів для датчиків та реле, параметри камер та таймери визначені як константи на початку файлу `main.py`. Перегляньте та за потреби змініть їх відповідно до вашого підключення та налаштувань.
    * Специфічні налаштування для модулів (наприклад, порогові значення для датчиків) можуть бути у відповідних файлах `core/*.py`.
